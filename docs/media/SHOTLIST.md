# Screenshot list

The README shows `chat.png` and `quickstart.gif` from this folder. Record these on a clean window 1440px wide, dark theme (Graphite), light: the text must stay readable at half size. Keep each under 1 MB.

1. **`chat.png`**: the chat panel mid-task.
   - Top bar with *Auto · Claude · Thinking*.
   - The live status line (*Running Bash: npm test · 42s · 2 helpers working*).
   - A folded *N steps* line.
   - A finished reply with its provider, tokens and cost line.

   Shows the panel is a real agent, not a prompt box.
2. **`quickstart.gif`**: first task in about 15 seconds: open the sidebar, the setup card, *Sign in to Claude* and *Set DeepSeek API Key*, type a task, press Enter, one permission card, the reply. Cut on the answer.
3. **`auto-split.gif`**: Auto mode handing over: the model pill changing from *Claude* to *DeepSeek* (or the reverse) between two tasks, with the Split tab open showing today's shares against the target.
4. **`cost.png`**: the token pill and its usage panel: cost by chat for the week, the busiest 10 minutes, and the Cost tab with a spend limit set. Shows what a day of work cost.
5. **`settings.png`**: the model pill's menu open (Model, Effort, Build mode), with the agents panel and the usage panel's tabs visible. Shows the knobs without a long table.
